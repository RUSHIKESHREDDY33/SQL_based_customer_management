Online Bookstore Database Project
This is my SQL project where I built a database for managing an online bookstore. I created this to practice my SQL skills and learn more about database design.
What I Built
I designed a database with tables for:

* Customers
* Books
* Orders
* OrderItems

The database lets you keep track of customers, what books you have in stock, and all the orders that customers have placed.
How to Set Up

1. Clone this repo to your computer
2. Make sure you have a SQL database installed (I used MySQL for this project)
3. Run the create_tables.sql script to set up the database structure
4. Run the sample_data.sql script if you want to add some test data

Main Features

* Store customer information (name, email, address, etc.)
* Catalog books with details like title, author, price, and genre
* Track orders and what books were purchased in each order
* Calculate order totals and keep track of shipping dates

Some Cool Queries I Wrote
I included several example queries that show how to:

* Find all books by a specific author
* See which customers spent the most money
* Check which books are bestsellers
* Find out which genres are most popular

What I Learned
Working on this project helped me understand:

* How to design tables with primary and foreign keys
* How to write JOIN queries to connect data from different tables
* How to use aggregate functions like COUNT, SUM and AVG
* How to filter data with WHERE clauses
